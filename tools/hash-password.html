🔐 パスワードハッシュ生成

入力したパスワードを SHA-256 でハッシュ化し、lib/config.js の PASSWORD_HASH に貼り付けるための 64 文字を表示します。
パスワード自体は送信されず、このページ内で計算されます。

ここにハッシュが表示されます
使い方: 上で生成したハッシュ文字列を lib/config.js の PASSWORD_HASH の値（シングルクォート内）に貼り付け、Git にコミットして GitHub Pages にデプロイすれば反映されます。

同等のコマンドライン:
echo -n "admin1234" | shasum -a 256 (macOS / Linux)
python3 -c "import hashlib;print(hashlib.sha256('admin1234'.encode()).hexdigest())"
